# stochastic_declustering_improvement

Faster, leaner reimplementation of Zhuang's stochastic declustering / space-time ETAS code
(https://bemlar.ism.ac.jp/zhuang/software.html), validated against the original outputs.

- `original/` — untouched upstream code + JMA example catalog (read-only).
- `src/`, `scripts/`, `tests/` — new code. `data/`, `results/` — inputs/outputs.

See `CLAUDE.md` for context, `architecture.md` for how the original works, `status.md` for
progress, `PROMPTS.md` for the session plan.
